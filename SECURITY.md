# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within HyperFrames Rust, please do not disclose it publicly. Send an email with reproduction details to `bhubbard@gmail.com`.
All security reports will be acknowledged within 48 hours and investigated promptly.
