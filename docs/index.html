The window.__hf Deterministic Seek Protocol

        
HyperFrames decouples render speed from realtime clock drift. Any HTML page exposing the seek protocol guarantees 100% frame reproduction.

      


      

        

          
Authoring for HyperFrames

          

            When HyperFrames renders an HTML document, it communicates over Chrome DevTools Protocol (CDP) to seek the page to exact timestamps:
          

          
<!DOCTYPE html>
<html>
<head>
  <meta name="hyperframes:duration" content="5.0">
  <meta name="hyperframes:fps" content="30">
  <meta name="hyperframes:resolution" content="1920x1080">
</head>
<body>
  <div id="hero">Render me</div>

  <script>
    window.__hf = {
      duration: 5.0,
      fps: 30,
      seek: function(timeSeconds) {
        // Synchronous frame-accurate update
        const p = timeSeconds / 5.0;
        document.getElementById('hero').style.transform =
          `translateX(${p * 500}px) rotate(${p * 360}deg)`;
      }
    };
  </script>
</body>
</html>

        


        

          
Automatic Virtual Clock Injection

          

            If an HTML page does not expose window.__hf, HyperFrames automatically injects a deterministic virtual clock shim before the page scripts execute:
          

          

            
    
              
  • 
                ✓
                performance.now() Interception: Advances strictly by 1 / fps per step, eliminating OS thread scheduling jitter.
              
    • 
              
  • 
                ✓
                requestAnimationFrame Freezing: Queues and executes animation callbacks synchronously on each captured frame.
              
    • 
              
  • 
                ✓
                Media Element Alignment: Locks <video> and <audio> element currentTime directly to the virtual transport clock.
              
    • 
              
  • 
                ✓
                Stall Detection & Smoothing: Ported lag smoothing with 4.6s playback stall detection so complex WebGL shaders never hang the render pipeline.

Native Rust Subsystems

        
Engineered for mission-critical video rendering pipelines with 100% test parity.

      


      

        

          
⏱

          
Exact Rational FPS

          
Full support for non-integer frame rates via exact rational arithmetic (Fps { num: 30000, den: 1001 } for 29.97 NTSC and 59.94) with [1, 240] bounds validation.

        


        

          
🛡

          
Hardened Safe Path Containment

          
Security guard ensuring all relative assets, textures, and output locations remain strictly bounded inside allowed project roots, preventing directory traversal and symlink escapes.

        


        

          
🎚

          
Audio Gain & Fade Envelopes

          
Logarithmic mixer fader coordinates ([-100, +100] $\leftrightarrow$ [-60dB, +12dB]) with linear fade-in / fade-out curve clamping and parametric audio automation lanes.

        


        

          
🎨

          
Color Grading & VFX Chains

          
Built-in broadcast LUT presets (neutral, warm-daylight, mono-clean, vintage-wash, bright-pop) with customizable shader capture chains and vignette effects.

        


        

          
📐

          
Even Dimension Padding

          
Automatic detection and padding filter generation for 4:2:0 subsampled formats (yuv420p) to prevent FFmpeg chroma misalignment errors on arbitrary canvas resolutions.

        


        

          
🔍

          
Fast FFprobe & Alpha Detection

          
Instant media stream interrogation with exact upstream regex evaluation for transparent alpha channel formats (yuva, rgba, bgra, ya8).
